# Shared context index

Read in order:

1. [Agent rules](../AGENTS.md): how to work and publish completed tasks.
2. [Project facts](PROJECT.md): confirmed scope, environment, and repository.
3. [Latest handoff](HANDOFF.md): current state, evidence, and continuation.
4. [Work log](WORKLOG.md): relevant completed changes.

Use the [task template](templates/TASK.md) for a substantial handoff. For concurrent agents, create separate task notes under `context/tasks/` with unique names, then reconcile the shared handoff when integrating the work.

Keep notes concise and evidence-backed. Store important context in these tracked Markdown files rather than relying on a previous chat or one agent's local memory. Do not invent product requirements or treat outdated notes as current code evidence.
